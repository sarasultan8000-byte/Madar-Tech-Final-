# Madar Tech

## تشغيل الموقع ولوحة التحكم

يلزم Node.js 20 أو أحدث.

1. افتح Terminal في مجلد المشروع وثبّت الحزم:

   ```sh
   npm install
   ```

2. أنشئ كلمة مرور إدارية محمية:

   ```sh
   npm run setup
   ```

   احفظ كلمة المرور التي تظهر في الطرفية؛ لن تُعرض مرة أخرى. تُحفظ بصمتها فقط في `.env`، والملف مستثنى من Git.

3. شغّل الخادم:

   ```sh
   npm start
   ```

4. افتح الموقع ولوحة الإدارة من الخادم نفسه:

   - الموقع: <http://127.0.0.1:3000/>
   - لوحة التحكم: <http://127.0.0.1:3000/dashboard.html>

   تُقدّم الصفحة ولوحة التحكم من الخادم نفسه، وتتصلان بقاعدة البيانات المركزية.

## التخزين والمصادقة

- المصدر الأساسي للمحتوى هو SQLite في `DATA_DIR/madar-tech.sqlite`. تُقرأ بيانات الصفحة الرئيسية من `GET /api/site`، وتقرأ لوحة التحكم المسودة وتحفظها عبر `GET/POST/PUT /api/draft`. يُستخدم `POST` للاستيراد الأولي فقط ولا يستبدل مسودة موجودة.
- تتوفر واجهات CRUD محمية لإدارة العناصر تحت `/api/content/:collection` للمجموعات: `sections`, `pages`, `services`, `projects`, `teamMembers`, `testimonials`, `faq`, و`messages`. يتطلب الإنشاء والتعديل والحذف جلسة إدارة صالحة.
- إذا كانت قاعدة البيانات فارغة، تستورد لوحة التحكم المسودة المحلية القديمة (المفتاح `madar-tech-homepage-v1` أو `madar-tech-dashboard-draft`) بعد تسجيل الدخول. لا يُحذف الملف المحلي؛ يُرسل المحتوى إلى قاعدة البيانات مرة واحدة. إذا كانت قاعدة البيانات تحتوي مسودة، لها الأولوية ولا تُستبدل بنسخة متصفح قديمة.
- إذا تغيّر نطاق الموقع عند الانتقال من GitHub Pages إلى Render، لا يستطيع المتصفح قراءة `localStorage` الخاص بالنطاق القديم. قبل الانتقال صدّر JSON من اللوحة القديمة، وبعد تشغيل Render سجّل الدخول وارفع الملف من زر **استيراد JSON**. يبقى الملف القديم محفوظًا، ويُطلب تأكيد قبل استبدال محتوى قاعدة البيانات.
- تُحدّث الصفحة الرئيسية محتواها من الخادم عند التحميل ثم تستطلع التغييرات كل 3 ثوانٍ، بحيث تظهر تعديلات المدير لجميع الزوار دون اشتراط تطابق تخزين المتصفحات.
- يستخدم تسجيل الدخول ملف تعريف ارتباط `HttpOnly` محدود المدة، وكلمة المرور لا تُخزن في المتصفح. لا تُقدّم قاعدة SQLite ضمن الملفات العامة.
- إعداد اللغة والوضع الفاتح/الداكن يبقى محفوظًا محليًا في المتصفح، ولا يتضمن محتوى الموقع.
- لتغيير كلمة مرور الإدارة محليًا شغّل `npm run reset-admin` ثم أعد تشغيل الخادم.

## النشر على Render

يتضمن المستودع `render.yaml` لخدمة Node على Render مع قرص دائم mounted على `/var/data`. يتطلب القرص الدائم خطة مدفوعة لدى Render.

1. شغّل محليًا `npm run setup` لإنشاء كلمة مرور الإدارة وبصمتها. لا ترفع `.env` إلى Git.
2. أنشئ Web Service على Render من المستودع باستخدام Blueprint `render.yaml`.
3. أضف في إعدادات الخدمة قيمتي `ADMIN_PASSWORD_SALT` و`ADMIN_PASSWORD_HASH` الموجودتين في `.env` كـ Secret Environment Variables. احتفظ بكلمة المرور التي طبعها `setup` وسلّمها للمدير فقط.
4. تأكد أن `DATA_DIR=/var/data` موجود، ولا تغيّر مسار Mount للقرص من `/var/data`.
5. بعد النشر اختبر `/api/health` ثم سجّل الدخول إلى `/dashboard.html` واحفظ تغييرًا. لاستخدام GitHub Pages بدل خدمة Render، يجب تغيير عنوان الواجهة ليتصل بالخدمة مع إعداد CORS وملفات تعريف الارتباط عبر النطاقات؛ الإعداد الحالي يخدم الموقع والـAPI من أصل واحد.
