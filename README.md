# Madar Tech

## تشغيل الموقع ولوحة التحكم

يلزم Node.js 20 أو أحدث.

1. افتح Terminal في مجلد المشروع وثبّت الحزم:

   ```sh
   npm install
   ```

2. أنشئ كلمة مرور إدارية محمية:

   ```sh
   npm run setup
   ```

   احفظ كلمة المرور التي تظهر في الطرفية؛ لن تُعرض مرة أخرى. تُحفظ بصمتها فقط في `.env`، والملف مستثنى من Git.

3. شغّل الخادم:

   ```sh
   npm start
   ```

4. افتح الموقع ولوحة الإدارة من الخادم نفسه:

   - الموقع: <http://127.0.0.1:3000/>
   - لوحة التحكم: <http://127.0.0.1:3000/dashboard.html>

   استخدم الموقع ولوحة التحكم من العنوان نفسه حتى تشتركا في بيانات المتصفح.

## التخزين والمصادقة

- تُحفظ المسودة بصيغة JSON كسلسلة في `localStorage` تحت المفتاح `madar-tech-dashboard-draft`. زر **تصدير JSON** في لوحة التحكم ينزّل نسخة ملف `madar-tech-draft.json`.
- عند أول تسجيل دخول في متصفح لا يحتوي على مسودة محلية، تُنسخ المسودة الموجودة في SQLite إلى هذا المتصفح مرة واحدة. بعد ذلك تحفظ تعديلات لوحة التحكم محليًا ولا تكتب فوق قاعدة البيانات.
- الصفحة الرئيسية تقرأ الجزء المنشور من المسودة المحلية، لذا تظهر التغييرات في ملف المتصفح نفسه وعلى الأصل نفسه فقط. لا تنتقل تلقائيًا إلى زوار آخرين أو أجهزة ومتصفحات مختلفة؛ النشر المشترك يتطلب تخزينًا خلفيًا.
- بيانات `localStorage` يمكن لأي JavaScript يعمل على الأصل نفسه قراءتها، لذلك لا تحفظ فيها معلومات حساسة. قاعدة SQLite الحالية تبقى موجودة ولا تُحذف.
- تسجيل الدخول للوحة التحكم ما زال يتطلب الخادم؛ كلمة المرور لا تُخزن في المتصفح، ويُستخدم ملف تعريف ارتباط `HttpOnly` محدود المدة. قاعدة البيانات لا تُقدّم ضمن الملفات العامة.
- إعداد لغة لوحة التحكم والوضع الفاتح/الداكن في الموقع يبقى كما هو ويُحفظ في `localStorage` بمفاتيح منفصلة عن المسودة.
- لتغيير كلمة مرور الإدارة محليًا شغّل `npm run reset-admin` ثم أعد تشغيل الخادم.

## سبب HTTP 405 السابق

كان الحفظ السابق يرسل `PUT /api/draft`، وهو طلب لا تعالجه استضافة الملفات الثابتة مثل Live Server. الحفظ الحالي للمسودة يتم في `localStorage` ولا يرسل `PUT`، لذلك لا يظهر خطأ 405 عند الحفظ. يبقى مسار الخادم لقراءة المسودة القديمة عند التهيئة الأولى.

## الاستضافة

لم توجد في المشروع إعدادات نشر أو معلومات تحدد مزود الاستضافة، لذلك لا يمكن تأكيد دعم استضافتك الحالية. التخزين المحلي في المتصفح لا ينشر التعديلات للزوار؛ لجعلها مشتركة على الموقع المنشور يلزم استخدام API وقاعدة بيانات على خادم دائم.

في بيئة الإنتاج اضبط `HOST=0.0.0.0` و`NODE_ENV=production`، واترك المنفذ من متغير `PORT` الذي توفره الاستضافة. عند تفعيل الإنتاج تصبح ملفات تعريف الارتباط آمنة (`Secure`) وتتطلب HTTPS.
